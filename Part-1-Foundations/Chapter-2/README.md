# Chapter 2: Prompting Techniques (Evolution Ladder)

This chapter explores the hierarchy of prompting techniques, from basic few-shot patterns to advanced agentic reasoning loops.

## Key Takeaways:
- The concept of the "Evolution Ladder" for AI tasks.
- **Level 1 (Foundations):** Zero-shot, Few-shot, Role prompting.
- **Level 2 (Reasoning):** Chain-of-Thought (CoT), Self-Consistency, Decomposition.
- **Level 3 (Agentic):** ReAct, Self-reflection, Tree-of-Thoughts.
- 8 real-world Python examples illustrating:
  - Dynamic few-shot selection using embeddings.
  - "Majority Vote" using self-consistency.
  - Chained pipelines for long-form content.
  - The ReAct agentic pattern.
  - Self-reflection for code quality.
  - System 2 (deliberative) reasoning.
  - Ambiguity handling and clarification.
  - Tree-of-Thought approach selection.
