# Chapter 1: The 4-Block Prompt Architecture

This chapter introduces the standard structural model for production prompts in 2026.

## Key Takeaways:
- Moving from "Blob" prompts to **Structured Specifications**.
- The 4 core blocks: **Role**, **Instructions**, **Context**, and **Output Contract**.
- Deep technical dive into **Persona Engineering**, **Success Criteria**, **Instruction Hierarchy**, and **API contracts**.
- 8 real-world Python examples illustrating:
  - Class-based prompt templates with Pydantic.
  - Security isolation using XML delimiters.
  - Strict JSON enforcement with "Prompt Anchoring."
  - Using "Success Criteria" checklists for complex tasks.
  - Controlling model "drift" with negative constraints.
  - Dynamic RAG context with "Source Attribution."
  - Zero-preamble formatting for high-volume tasks.
  - Multi-step logic using Chain-of-Thought (CoT) anchoring.
