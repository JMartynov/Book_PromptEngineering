# Chapter 4: Context Engineering

This chapter explores the shift from "Prompt-centric" to "Context-centric" design in AI system engineering.

## Key Takeaways:
- Context is the **Data Layer** of the modern AI prompt.
- The 3 pillars: **Semantic Memory (RAG)**, **Episodic Memory (History)**, and **Working Memory (Tasks)**.
- Deep technical dive into **Attention Budget**, **Lost in the Middle**, and **Recency Bias**.
- 8 real-world Python examples illustrating:
  - **Reranking** for high-signal retrieval.
  - **Context Compression** with summary headers.
  - **Context-First** prompt ordering.
  - **Schema Headers** for data isolation.
  - **Metadata Filtering** for user privacy.
  - **Progressive Disclosure** using skill routers.
  - **Context Resolution** for handling data conflicts.
  - **Self-Correction** with context sufficiency checks.
