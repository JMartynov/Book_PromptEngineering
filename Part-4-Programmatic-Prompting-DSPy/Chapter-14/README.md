# Chapter 14: GEPA (2025 Breakthrough)

This chapter introduces the Genetic-Pareto (GEPA) optimizer, a 2025 breakthrough in reflective prompt evolution.

## Key Takeaways:
- Moving from Reinforcement Learning (RL) to **Reflective Learning**.
- The 3 pillars of GEPA: **Trajectory Sampling**, **Natural Language Reflection**, and **Pareto Frontier Evolution**.
- Why natural language feedback is **35x more sample-efficient** than scalar rewards.
- 8 real-world Python examples illustrating:
  - Defining **Agent Trajectories** (Thought/Action/Observation) for deep analysis.
  - Generating **Reflective Diagnoses** from failed runs using "Meta-Prompts."
  - Automating **Rule-Based Prompt Evolution**.
  - Balancing metrics (accuracy vs. cost) on the **Pareto Frontier**.
  - **Prompt Breeding**: Cross-pollinating successful instructions from different candidates.
  - Implementing **Iterative Inference-Time Reflection** to increase the accuracy floor.
  - Comparing **Scalar Rewards vs. Rich Language Feedback** efficiency.
  - Automatically documenting **"Lessons Learned"** for human knowledge transfer.
