# Chapter 11: DSPy — Programming, Not Prompting

This chapter introduces the fundamental shift from "Prompt Engineering" (writing text) to "Programmatic AI" (writing code that generates text).

## Key Takeaways:
- DSPy as the **Compiler** for the modern AI system.
- The 3 pillars: **Signatures (Logic)**, **Modules (Scaffolding)**, and **Optimizers (Search)**.
- Deep technical dive into **Separation of Concerns**, **Teleprompters**, and **Language Model Programming**.
- 8 real-world Python examples illustrating:
  - Basic **Declarative Signatures** for sentiment analysis.
  - Using the **ChainOfThought** reasoning module.
  - Multi-input signatures for **RAG**.
  - Building custom **Agent Modules**.
  - Adding **Assertions** for self-correcting logic.
  - Compiling with **BootstrapFewShot** optimizers.
  - Handling structured output with **Descriptors**.
  - **Zero-Effort Model Migration** (GPT-4 to Llama 3).
